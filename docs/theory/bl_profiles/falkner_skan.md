# Falkner–Skan Profiles

The Falkner–Skan family provides **exact similarity solutions** of the
boundary layer equations for edge velocities of the form
$U_e(x) \propto x^m$, corresponding to power-law pressure gradients.

## Governing ODE

$$f''' + f\,f'' + \beta\bigl(1 - f'^2\bigr) = 0$$

with boundary conditions $f(0) = 0$, $f'(0) = 0$, $f'(\infty) = 1$,
where:

$$\beta = \frac{2m}{m+1}$$

The similarity variable is:

$$\eta = y\sqrt{\frac{(m+1)\,U_e}{2\nu s}} = \frac{y}{L}, \qquad
L = \sqrt{\frac{2\nu s}{(m+1)\,U_e}}$$

This reduces to the **Blasius equation** at $\beta = 0$ ($m = 0$, zero
pressure gradient), though with a different similarity variable scaling
— see the [Blasius page](blasius.md) for details on the $\sqrt{2}$
difference.

## Key Constants

The ODE is solved numerically for each $\beta$. The key integrals:

$$I_1(\beta) = \int_0^\infty(1-f')\,d\eta, \qquad
I_2(\beta) = \int_0^\infty f'(1-f')\,d\eta$$

$$H(\beta) = \frac{I_1}{I_2}, \qquad S(\beta) = f''(0) \cdot I_2$$

- At $\beta = 0$: flat plate (Blasius-equivalent)
- At $\beta = 1$: stagnation point (Hiemenz flow)

The full tabulated data (26 $\beta$ values, 200 $\eta$ points each) is
stored in `data/bl-solver-profiles/falkner_skan.json` and loaded by
`FalknerSkanTable`.

## Closure Relations

$$H = H(\beta) \quad \text{(tabulated)}$$

$$\frac{c_f}{2} = \frac{S(\beta)}{Re_\theta} \quad \text{(tabulated)}$$

The solver looks up $H$ and $S$ from the table for the local $\beta$
value at each station.

## Stagnation Patching

At the stagnation point, $m = 1$ and $\beta = 1$ (Hiemenz flow). The
similarity variable simplifies to $\eta = y\sqrt{K/\nu}$ since
$(m+1)/2 = 1$.

The integral thicknesses become constants (independent of $s$):

$$\delta^* = \sqrt{\frac{\nu}{K}}\,I_1, \qquad
\theta = \sqrt{\frac{\nu}{K}}\,I_2$$

From the numerical solution at $\beta = 1$:

| Quantity | Symbol | Value |
|----------|--------|-------|
| Wall shear parameter | $f''(0)$ | $1.23259$ |
| Displacement integral | $I_1$ | $0.64790$ |
| Momentum integral | $I_2$ | $0.29235$ |
| Shape factor | $H$ | $2.2162$ |
| Shear parameter | $S = f''(0) \cdot I_2$ | $0.36028$ |

$$\boxed{\theta^2_\text{stag} = I_2^2\,\frac{\nu}{K}
= 0.08547\,\frac{\nu}{K}}$$

$$\delta^*_\text{stag} = H\,\theta_\text{stag}
= 2.216\,\theta_\text{stag}$$

**This is the exact reference solution** — all other stagnation patching
methods approximate it.

## Velocity Field Reconstruction

### Inverting $H$ to $\beta$

The solver stores $H$ at each station. Since $H(\beta)$ is monotonic
for $-0.1988 < \beta \le 2$, the table can be inverted:

$$\beta = H^{-1}(H_\text{solver})$$

This inversion uses the same `FalknerSkanTable` that the closure
relation uses, via the `constants_from_H(H)` method.

### Recovering $\delta_{99}$

$$L_i = \frac{\theta_i}{I_2(\beta_i)}$$

$$\delta_{99,i} = \eta_{99}(\beta_i) \cdot L_i
= \frac{\eta_{99}(\beta_i)}{I_2(\beta_i)}\,\theta_i$$

The ratio $\delta_{99}/\theta$ varies with $\beta$:

| $\beta$ | $\delta_{99}/\theta$ |
|---------|---------------------|
| $0$ (Blasius) | $5.0/0.6641 \approx 7.53$ |
| $0.5$ | $\sim 3.5/0.4284 \approx 8.2$ |
| $1.0$ (Hiemenz) | $\sim 2.4/0.2924 \approx 8.2$ |

### Reconstruction Procedure

At each station $s_i$:

1. From $H_i$, invert the table to get $\beta_i$
2. Look up $I_2(\beta_i)$ and the profile function $f'_{\beta_i}(\eta)$
3. $L_i = \theta_i / I_2(\beta_i)$
4. $\delta_{99,i} = \eta_{99}(\beta_i) \cdot L_i$
5. For any $y$: $\eta = y/L_i$, then
   $u_i(y) = U_{e,i} \cdot f'_{\beta_i}(\eta)$

The profile $f'_\beta(\eta)$ is interpolated in both $\beta$ and $\eta$
from the stored Falkner–Skan table via `fprime_from_H(H, eta)`.

## Table Generation

The tabulated data is generated by `scripts/generate_falkner_skan_table.py`,
which uses a shooting method with the **Topfer scaling trick** for
$\beta = 0$ and standard shooting with terminal events (`f' > 2` or
`f' < -1`) and `max_step=0.5` for $\beta \neq 0$ to prevent solver
hangs on stiff/divergent solutions.

For out-of-range $\beta$ values, the `FalknerSkanTable` class falls back
to solving the ODE on-the-fly.
